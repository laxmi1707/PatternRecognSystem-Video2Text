Video2Knowledge Pipeline Data Flow

From screen recording upload to classified activity timeline — 150-dimensional multimodal feature extraction

1
Input Ingestion

User uploads a screen recording video (.mp4) and optional action log (.json) via the React frontend or REST API.

Video File
Screen recording (.mp4)
e.g. 2940×1912, 60fps
CUA-Suite format
~2-50 MB
Action Log
JSON with timestamped actions:
CLICK, MOVE_TO, TYPING,
DRAG_TO, HOTKEY, PRESS
~1-10 KB
Model Selection
User picks classifier:
14 models across 3 tiers
Default: SVM
Save to disk → Create Video + AnalysisJob in DB → Trigger job run
2
Video Segmentation

VideoProcessor (OpenCV) extracts keyframes at 1 FPS, resizes to 640×480, then clusters actions by 2-second temporal gaps into segments.

Frame Extraction
cv2.VideoCapture → sample 1 frame/sec → cv2.resize(640,480)
~1 frame/sec
Action Clustering
Sort by timestamp → group by 2.0s gap threshold → N clusters
gap = 2.0s
SegmentData
segment_index, start_time, end_time, keyframes[ ], actions[ ]
N segments
Each segment processed independently through 4 modality extractors
3
Multimodal Feature Extraction

Four parallel extractors process each segment's keyframes and actions into a 150-dimensional feature vector.

📝
OCR Text
EasyOCR + Tesseract fallback
Read text from keyframes → concatenate → TF-IDF vectorize (top 50 terms from corpus)
50 dims [0:50]
💻
UI Elements
YOLOv8n (COCO → UI mapping)
Detect objects → map to 12 UI types → counts[12] + spatial[8] + confidence[4] + complexity[6]
30 dims [50:80]
🎨
Visual
OpenCV (pure image processing)
Color histogram[18] + Canny edges[3] + Gabor texture[6] + scene stats[5] + layout grid[8]
40 dims [80:120]
🖱
Interaction
Action log parsing
Action freq[8] + click pos[4] + temporal[6] + mouse move[6] + typing[4] + keyboard[2]
30 dims [120:150]
Concatenate 4 modality vectors into single feature vector per segment
4
Feature Assembly + Temporal Encoding

FeatureAssembler concatenates modalities. TemporalEncoder smooths adjacent segments (70% self + 30% neighbor mean).

Feature Vector: 150 dimensions per segment
[0:50] OCR  |  [50:80] UI  |  [80:120] Visual  |  [120:150] Interaction
TemporalEncoder: encoded[i] = 0.7 × segment[i] + 0.3 × mean(neighbors)
X shape: (N_segments, 150)
Feature matrix X fed to selected classifier (lazy-trained on CUA-Suite dataset)
5
Multi-Tier Classification

Selected classifier predicts activity label per segment. Models lazy-train on first use from real CUA-Suite dataset (28 tasks, augmented if <100 samples).

Tier 1 — Classical ML
  • SVM — maximum margin, RBF kernel
  • Naive Bayes — probabilistic, Gaussian
  • Decision Tree — rule-based, interpretable
  • Random Forest — bagging, 100 trees
  • KNN — instance-based, k=5
  • XGBoost — gradient boosting
  • LightGBM — histogram boosting
Tier 2 — Deep Learning
  • MLP — 2-layer feed-forward NN
  • CNN1D — 1D conv for local patterns
  • LSTM — recurrent, seq_len=15
  • Transformer — self-attention, 2 heads
All share TorchBaseClassifier
Adam, CrossEntropy, 20 epochs
Tier 3 — Ensemble
  • Voting — soft vote over SVM+RF+MLP
  • Stacking — LogReg meta-learner
  • Late Fusion — per-modality branches
    using MODALITY_MAP slicing
Late Fusion: each branch sees
only its modality's feature columns
Per-segment predictions: label + confidence + probability distribution over 10 classes
6

Classification results persisted to DB, returned to frontend as a workflow timeline with per-segment activity labels.
