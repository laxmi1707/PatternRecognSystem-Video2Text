Request Sequence: Upload → Classify → Results
Step From To Method / Action Data
1 Browser → videos router POST /api/v1/videos/upload multipart: file + action_log + model_name
2 videos router → Disk aiofiles.write() Save .mp4 + .action_log.json to uploads/
3 videos router → VideoProcessor get_metadata(path) OpenCV reads fps, duration, resolution
4 video_service → SQLite INSERT videos, analysis_jobs Video record + queued AnalysisJob
5 Browser ← videos router 201 Created {id, filename, status, job_id}
6 Browser → jobs router POST /api/v1/jobs/{id}/run Trigger classification pipeline
7 classification_service → VideoProcessor extract_segments(video, actions) Keyframes at action timestamps + clustering
8 FeatureAssembler → 4 Extractors extract_segment_features(seg) OCR[50] + UI[30] + Visual[40] + Interaction[30]
9 TemporalEncoder → Feature Matrix encode_sequence(X) Smooth: 0.7*self + 0.3*neighbor_mean
10 ml_service → Classifier clf.fit(X_train, y) + clf.predict(X) Lazy-train on CUA-Suite, then predict segments
11 classification_service → SQLite INSERT classification_results Per-segment: label, confidence, probabilities
12 Browser ← jobs router 200 OK {job_id, status, results: ClassificationResult[]}
