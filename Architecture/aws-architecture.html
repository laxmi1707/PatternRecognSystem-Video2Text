Data Flow: Video → Pattern Recognition → Knowledge
1. UPLOAD
User uploads video via React UI → presigned URL → S3 bucket
2. PREPROCESS
Lambda extracts frames + audio tracks for parallel recognition
3. SPEECH PATTERNS
AWS Transcribe detects speech patterns → timestamped transcript
4. VISUAL PATTERNS
CNN classifies scenes; RNN/Transformer detects action sequences + temporal patterns
5. TEXT PATTERNS
Rekognition/Textract extracts on-screen text (UI elements, code, labels)
6. FUSION
Multimodal fusion combines all pattern signals → unified embeddings
7. STORE
Embeddings + structured steps stored in pgvector + PostgreSQL
8. RETRIEVE
RAG pipeline retrieves relevant knowledge from recognized patterns
