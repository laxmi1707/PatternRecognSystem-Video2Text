Data Flow: Video → Multi-Tier Classification → Knowledge
1. UPLOAD
User uploads video via React UI → presigned URL → S3 bucket
2. PREPROCESS
Lambda extracts frames → scene segmentation → keyframe detection → cursor tracking
3. FEATURE EXTRACTION
Parallel: OCR→text (Textract) | UI detection (YOLO) | Cursor/click detection | Window state tracking
4. TIER-1 CLASSIFY
Classical ML: SVM, RF, NB, DT classify activity type (Git, Docker, K8s, Terraform, AWS, Jenkins)
5. TIER-2 CLASSIFY
Deep Learning: CNN scene classification + LSTM/Transformer temporal sequence recognition
6. TIER-3 ENSEMBLE
Ensemble: Voting + Stacking combine Tier 1+2 → multimodal fusion → final workflow label + confidence
7. GENERATE
LLM (Bedrock) generates SOP, timeline, knowledge article from classified workflow steps
8. STORE
Embeddings → pgvector | Structured data → PostgreSQL | Documents → S3/DynamoDB
9. RETRIEVE
RAG pipeline: user query → embedding → vector search → LLM-augmented response
