4
Multi-Tier Classification
3-tier classifier hierarchy: Classical ML → Deep Learning → Ensemble Fusion
Fused Input
Per-segment feature vector:
• OCR text content
• UI element labels
• Cursor & click events
• Window state transitions
• Scene classification
→
Target Classes
git_operations
docker_workflow
kubernetes_ops
terraform_iac
aws_console
jenkins_ci_cd
coding_editing
debugging
documentation
other
→
Output
workflow_label: string
confidence: float (0-1)
tier_votes: {t1, t2, t3}
temporal_sequence: ordered steps
explanation: feature importance
Tier 1: Classical ML
Input: TF-IDF + hand-crafted features
Models: SVM, Naive Bayes, Decision Tree, Random Forest, KNN, XGBoost, LightGBM
Output: Per-model class probabilities
Purpose: Fast baseline + interpretable
Tier 2: Deep Learning
Input: Raw embeddings + sequences
Models: CNN (scene), LSTM (temporal), Transformer (action), ViT (visual), HMM/CRF (sequence)
Output: Learned representations + class probs
Purpose: Capture complex patterns
Tier 3: Ensemble + Fusion
Input: Tier 1 + Tier 2 predictions
Models: Voting Classifier, Stacking Classifier, Multimodal Late Fusion, CLIP alignment
Output: Final label + confidence + explanation
Purpose: Maximize accuracy

7
RAG Retrieval & Search
User queries → semantic search → LLM-augmented answers
User Query
"How do I deploy with Terraform?"
"Show me Docker build steps"
"Find all K8s deployments"
→
RAG Pipeline
1. Embed query (Sentence Transformers)
2. Vector similarity search (pgvector)
3. Retrieve top-K chunks
4. Re-rank results
5. LLM generates answer with citations
FastAPI → pgvector → Bedrock (Claude) → Response
→
Response
LLM answer with source citations
Linked SOP documents
Video timestamp references
Confidence score per source
